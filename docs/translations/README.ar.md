<h1 align="center">Escalated for Laravel</h1>

<p align="center">
  أضف مكتب دعم متكاملًا إلى تطبيق Laravel الخاص بك.<br>
  تذاكر، واتفاقيات مستوى الخدمة (SLA)، وقواعد تصعيد، وصندوق وارد للوكلاء، وبوابة للعملاء، تعمل كلها على قاعدة بياناتك الخاصة.

## الميزات

<table>
<tr>
<td width="33%" valign="top">

**التذاكر**
- الإنشاء والإسناد والرد والحل وإعادة الفتح
- انتقالات حالة قابلة للتهيئة
- فصل رد إلى تذكرة جديدة
- تأجيل مع استئناف تلقائي
- الوسوم والمرفقات وسجل النشاط

</td>
<td width="33%" valign="top">

**مساحة عمل الوكيل**

- إجراءات جماعية وملاحظات داخلية
- ردود جاهزة
- أقسام مع إسناد بالتناوب
- تحديثات فورية مع رجوع إلى الاستطلاع الدوري

- أهداف الاستجابة والحل لكل أولوية
- ساعات العمل
- كشف تلقائي لحالات الخرق
- قواعد تصعّد أو تعيد الإسناد أو ترسل إشعارات

</td>
</tr>

<td width="33%" valign="top">

- أداة أو نموذج أو دردشة مباشرة قابلة للتضمين

## البدء السريع

```bash
composer require escalated-dev/escalated-laravel
npm install @escalated-dev/escalated
php artisan escalated:install
php artisan migrate
```

ثم افتح `/support`. يتطلب PHP 8.2+ وLaravel 11.39 أو أحدث. يشرح [دليل البدء](../getting-started.md) إعداد نموذج المستخدم وبوابات الوصول (gates).
